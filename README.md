# 미원부동산 마포구 아파트 브리핑 대시보드

서울 마포구 아파트 시장을 고객에게 설명하기 위한 대시보드입니다. 서버 없이 `index.html`을 더블클릭하면 바로 열립니다.

상담문의: 미원부동산 010-3699-1597

## 주요 기능

- 동별 조회, 주간 / 월간 / 3개월 / 날짜 직접지정
- 매매·전세·월세 TOP10 (최고가·거래량·평당가 순)과 지도 표시
- 단지별 최근 실거래가와 입지분석 (교통, 학군, 상권, 개발계획)
- 추천매물 추가·수정·삭제
- 가격지수, 거래량, 미분양 차트
- 인쇄 / PDF 저장

## 사용 방법

1. 이 저장소를 내려받습니다.
2. `index.html`을 더블클릭합니다. 지도를 보려면 인터넷 연결이 필요합니다.

## 자료 갱신

1. Node.js 22 이상을 설치합니다.
2. `tools/api_keys.example.txt`를 복사해 `tools/api_keys.txt`를 만들고 본인의 API 키를 넣습니다.
   공공데이터포털과 한국부동산원 R-ONE에서 발급받을 수 있습니다.
3. `update_data.bat`을 실행합니다. 이 파일 안의 Node.js 경로는 설치 위치에 맞게 고쳐야 할 수 있습니다.

## 유의사항

- 본 자료는 참고용이며, 실제 거래 시 등기부등본과 관련 공부를 반드시 확인하시기 바랍니다.
- 일부 단지는 지도에 동 중심 기준의 근사 위치로 표시됩니다.
- 추천매물 4건은 샘플이며 실제 매물이 아닙니다.
- 개발계획은 일정과 내용이 바뀔 수 있으니 관계기관의 최신 고시를 확인하시기 바랍니다.
- 추가한 매물과 위치 수정 내용은 사용하는 브라우저에만 저장됩니다.
